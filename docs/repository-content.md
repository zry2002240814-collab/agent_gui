# GitHub 仓库文件收录说明

目标仓库：<https://github.com/zry2002240814-collab/agent_gui>。

本次按“能理解项目、能安装、能复现离线测试、能接入真机”的标准整理。源码与可复现的输入纳入版本控制；运行产物、个人文件、缓存和来源未确认的外部安装包不纳入。

## 纳入的内容

| 内容 | 用途与收录理由 |
|---|---|
| `agent.py` | 主入口，承载任务状态、预算、模型决策和 Critic 编排 |
| `utils/gui_agent/*.py` | 将任务、观察、证据、协议、路由与规则分开实现，便于阅读和维护 |
| `utils/gui_agent_skills.json` | 静态技能属于运行输入，必须与代码一起版本化 |
| `agent_base.py`、`device_controller.py` | 提供模型与设备接口，是完整运行链路的必要组成部分 |
| `run_tests.py`、`test_runner.py` | 支持任务执行、断点续跑和轨迹保存 |
| `utils/__init__.py`、`image_utils.py`、`visualize.py` | 模块入口及现有图像、轨迹可视化辅助代码 |
| `requirements.txt` | 保留原框架依赖，供环境安装；本次未改依赖版本 |
| `tasks/tasks.json` | 10 个可读示例，展示任务格式及单 App、跨 App 场景；不是成功率基准 |
| `tests/test_gui_agent.py` | 47 项离线回归测试，既验证核心行为，也验证固定框架文件未被修改 |
| `docs/gui-agent-redesign.md` | 保存重构设计依据与范围，帮助理解架构选择 |
| `docs/gui-agent-implementation.md` | 说明最终实现、配置、验证方式及限制 |
| `README.md`、`.gitignore`、`.gitattributes` | 提供项目入口说明、排除本地生成物，并保留固定框架文件的字节内容 |

五个固定框架文件保留原始字节内容。本地 Git 配置使用 `core.autocrlf=false`，并在 `.gitattributes` 中为这些文件设置 `-text`，避免提交与后续检出时转换换行符，导致现有 SHA-256 回归检查失败。

## 不纳入的内容

| 内容 | 原因与处理 |
|---|---|
| `output/` | 本地运行结果与个人文档；其中现有简历与本项目发布无关，全部排除 |
| `.tmp/` | 含个人文档编辑脚本、渲染图片与预览文件，属于临时工作资料 |
| 所有 `__pycache__/`、`*.pyc` | Python 自动生成，可在运行时重建 |
| `ADBKeyboard.apk` 及其他 `*.apk` | 外部二进制依赖，当前工作区未附来源、版本及许可材料；不随首次代码提交分发，README 说明另行准备 |
| 虚拟环境、IDE 配置、日志 | 属于机器或运行状态，不影响源码复现 |
| `.env*`、本机云服务或代理配置目录 | 可能包含凭据或个人配置，排除；模型 Key 使用环境变量传入 |

本次没有添加 LICENSE，也没有为已有框架或 APK 推断开源许可。后续如需要明确的开源授权，应先核对已有框架与外部材料的来源和许可。

## 文档与代码边界

- 保留设计文档中的方案说明，同时通过实现文档区分已实现能力与设计意图。
- 设计文档中的本机微信文件路径改为材料名称，移除外部读者无法访问的个人路径；原 PPT 不随仓库分发。
- README 明确固定模型端点、中文输入的外部依赖，以及当前缺少 `generate_html.py` 的事实。
- 不发布未复现的成功率、性能或成本数字。
- 默认示例涉及评论发布、预订及位置查询；使用者应调整任务内容和日期后再运行。
- 截图和日志若用于公开演示，应另行挑选并去除账号信息、私人内容与位置数据，不自动将 `output/` 纳入仓库。
